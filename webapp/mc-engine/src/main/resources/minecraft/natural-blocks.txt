# Blocks that world generation places, derived from the Minecraft server jar.
# Regenerate with webapp/scripts/dump-structure-density.py -- do not hand-edit.
#
# Answers one question: is breaking this block *mining*, or is it re-collecting
# something a player put down? A beacon is only ever placed. Terracotta is what a
# badlands is made of. Before this file the model could not tell them apart and
# treated any craftable block as re-collection, which removed mining terracotta as
# an option entirely (MCO-527).
#
# [terrain]  the surface rules -- what the ground is made of.
# [feature]  what worldgen puts into it: ores, disks, vegetation, trees.
# Both count as natural; they are kept apart because they are different claims and
# a later reader may want only one.
#
# KNOWN GAP, and it is one rule rather than a general failure: `minecraft:bandlands`
# is a surface-rule type whose terracotta palette lives in code, not in the JSON. So
# plain, white and orange terracotta are listed and the four banded colours (red,
# yellow, brown, light gray) are not. Dyed terracotta is crafted from plain, so the
# chain prices them correctly anyway -- but a reader looking for red_terracotta here
# and not finding it is seeing a limit of the data, not a bug in the extraction.
#
# Structure-placed blocks are NOT here: they are membership in structure-density.txt,
# where they carry a rarity as well. A block in a structure and nowhere else is
# findable but not natural, and the two are priced differently.
